# repocomic: plan to v1.0

## Concept

`npx repocomic owner/repo` writes a comic-book poster of a GitHub repository: the title splashed across the cover, a starburst with the star count, the origin story (creation date and description in a speech bubble), the heroes (top contributors), the powers (languages) and the saga (a year of weekly commits). It is the image a maintainer posts when announcing a release, or embeds in a README.

## Architecture

```
owner/repo ──► github.ts ──► RepoStats ──► layout.ts ──► element tree ──► satori ──► SVG ──► resvg ──► PNG
                  ▲                            ▲
             GITHUB_TOKEN               themes.ts · formats
         (or --from-json file)
```

| Module | Responsibility |
|---|---|
| `stats.ts` | The `RepoStats` type and its validation when read from JSON. |
| `github.ts` | Fetch repo, languages, contributors, weekly commit activity and latest release from the REST API; retries the 202 "stats are being computed" response. |
| `themes.ts` | Colour themes (`classic`, `noir`, `pop`). |
| `layout.ts` | Pure functions from `RepoStats` + theme + format to a Satori element tree. |
| `render.ts` | Fonts, avatars (embedded as data URIs), Satori to SVG, resvg to PNG. |
| `cli.ts` | Argument parsing, output path, `--from-json` / `--save-json`. |

## Decisions

- **TypeScript + Satori + resvg.** Satori lays out flexbox and text with real fonts into SVG; resvg rasterises it without a browser. No headless Chrome.
- **Fonts bundled:** Bangers and Comic Neue, both SIL OFL 1.1, licence files shipped next to them.
- **No React at runtime.** A ten-line `h()` builds the element objects Satori expects; `@types/react` is a dev dependency for Satori's types.
- **Offline-first tests:** the GitHub client takes an injectable `fetch`; tests use recorded API responses. Avatars fall back to initials when they cannot be downloaded.
- **Formats:** `poster` 1080 × 1350 (Instagram / LinkedIn portrait) and `card` 1200 × 630 (Open Graph / X).

## Scope v1.0

1. GitHub stats with optional token, rate-limit message and retries.
2. Poster and card layouts, three themes.
3. PNG and SVG output.
4. CLI with `--theme`, `--format`, `--output`, `--from-json`, `--save-json`.
5. Library API (`fetchRepoStats`, `renderPoster`).
6. Tests on recorded data; CI on Linux, macOS and Windows.

## Out of scope

GitHub Action, web app, user posters (profile rather than repository), animated output, GitLab.
